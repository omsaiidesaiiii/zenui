# Button

A premium, highly-customizable button component with multiple variants and states.

## Installation

```bash
npx zen-ui-cli add button
```

## Usage

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return (
    <Button variant="default" size="md">
      Click me
    </Button>
  );
}
```

## Variants
- `default`
- `secondary`
- `outline`
- `ghost`
- `danger`
